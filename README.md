# slovo

![Пост, вставленный из чата с нейросетью: /slovo снимает следы нейросети, а цифра «12 %» и тире остаются на месте; дешёвый хьюманайзер выпалывает тире и пишет «рухнула вдвое», slovo возвращает как было](promo/slovo.gif)

Скилл для ИИ-агентов, который правит и пишет русский текст по-человечески и при этом не врёт.

Обычный «хьюманайзер» делает текст живее ценой точности: дописывает связки, округляет цифры, превращает «совпадает по времени» в «из-за», а «три версии не объясняют спад» в «ни одна версия ничего не объясняет». Читатель этого не заметит. Автор заметит слишком поздно.

`/slovo` держит две оси сразу. Первая — смысл: каждое утверждение после правки значит то же, что до неё, с теми же цифрами, охватом, уверенностью и оговорками. Вторая — язык: глагол вместо отглагольного существительного, ударение там, где новое, никакого канцелярита, калек и нейросетевой гладкости. Текст, который стал живее, но соврал, считается провалом. Текст, который остался точным, но ватным, — тоже.

## Что внутри

- `slovo/SKILL.md` — инструкция для агента в трёх частях: что нарушать нельзя, редакторские приёмы, проверка после работы.
- `slovo/examples.md` — пары «было → стало»: хорошие правки (в том числе по правилам Пушкина, Чехова, Оруэлла, Уильямса и Сорд), абзац, который правильно не тронули, и разбор перекрученных правок, каждая из которых выглядит гладко и меняет смысл.
- `slovo/check.py` — сверка правки с исходником, только стандартная библиотека Python. Останавливает правку, если потерялось или появилось число, если «5 %» стало «5 п. п.», если пропало тире. Отдельно показывает места, где фраза получила «вдвое», «обвал», «всей», «поэтому» или потеряла оговорку, — с цитатой, чтобы перечитать.
- `slovo/tests/` — регрессионные тесты для `check.py`: плохая правка должна быть помечена, хорошая — нет.

## Откуда это

Скилл вырос из правки 32 аналитических отчётов. Те, кто правил, проверили себя сами и пропустили 17 искажений смысла; свежая независимая сверка их нашла. Из этих ошибок сделаны правила, примеры и тесты (обезличенные). На тех же отчётах `check.py` помечает 13 из 17 таких ошибок и ни разу не падает на правках, которые человек признал верными. Оставшиеся четыре — подмена группы, дописанное следствие, дописанный признак, переехавшая ссылка — словами не ловятся, их ищет холодная сверка, которую скилл велит отдать отдельному агенту.

Язык — от Норы Галь («Слово живое и мёртвое») и Корнея Чуковского («Живой как жизнь», откуда само слово «канцелярит»). Ещё три правила взяты у тех, кто сформулировал их раньше всех: называть вещь её именем, а не описательным оборотом (Пушкин, «О прозе»); вычёркивать украшающие определения, но не те, что сужают утверждение (Чехов, письмо Горькому); менять стёртую метафору и эвфемизм на простые слова (Оруэлл, «Политика и английский язык»). Из современных авторов взят один приём и несколько примеров. Приём — от Стивена Пинкера («Чувство стиля»): если автор пропустил шаг между двумя утверждениями, редактор не дописывает его, а спрашивает автора. Примеры — по Джозефу Уильямсу («Style: Lessons in Clarity and Grace»: кто действует, тот подлежащее; известное в начале фразы, новое в конце) и Хелен Сорд (её «зомби-существительные», отглагольные слова вместо глагола). Принцип «удаляй, не дописывай» и сверка с исходником — от [humanizer-ru](https://github.com/ilyautov/humanizer-ru). Одно правило оттуда убрано сознательно: тире автора здесь не трогаются. Русская проза держится на тире, и выпалывать его ради «нечеловеческого» вида — та же порча, что и канцелярит.

## Установка

Скилл — это папка `slovo` с файлом `SKILL.md` внутри, по открытому формату Agent Skills. Её понимают большинство агентов; различается только место, откуда они её берут. Ниже `danzerzine/slovo` — адрес этого репозитория на GitHub.

### Одна копия для всех агентов

```bash
git clone https://github.com/danzerzine/slovo.git ~/slovo-skill
```

```bash
mkdir -p ~/.agents/skills ~/.claude/skills && ln -s ~/slovo-skill/slovo ~/.agents/skills/slovo && ln -s ~/slovo-skill/slovo ~/.claude/skills/slovo
```

Папку `~/.agents/skills` читают Codex, Gemini CLI, Cursor, GitHub Copilot и OpenCode, папку `~/.claude/skills` — Claude Code (OpenCode читает обе). Обновить скилл: `git -C ~/slovo-skill pull`.

### По агентам

| Агент | Для всех проектов | Для одного проекта |
|---|---|---|
| Claude Code | `~/.claude/skills/slovo/` | `.claude/skills/slovo/` |
| Codex (OpenAI) | `~/.agents/skills/slovo/` | `.agents/skills/slovo/` |
| Gemini CLI | `~/.gemini/skills/slovo/` или `~/.agents/skills/slovo/` | `.gemini/skills/slovo/` или `.agents/skills/slovo/` |
| Cursor | `~/.cursor/skills/slovo/` или `~/.agents/skills/slovo/` | `.cursor/skills/slovo/` или `.agents/skills/slovo/` |
| GitHub Copilot (CLI, VS Code, облачный агент) | `~/.copilot/skills/slovo/` или `~/.agents/skills/slovo/` | `.github/skills/slovo/` или `.agents/skills/slovo/` |
| OpenCode | `~/.config/opencode/skills/slovo/` или `~/.agents/skills/slovo/` | `.opencode/skills/slovo/` или `.agents/skills/slovo/` |

У двух агентов есть своя команда установки:

```bash
gemini skills install https://github.com/danzerzine/slovo.git --path slovo
```

```bash
gh skill install danzerzine/slovo slovo --agent claude-code --scope user
```

`gh skill install` (GitHub CLI) ставит скилл в нужную папку для выбранного агента: вместо `claude-code` можно указать `github-copilot`, `cursor`, `opencode` и другие.

### Claude в браузере и в приложении

Заархивируйте папку `slovo` в ZIP и загрузите: Customize → Skills → «+» → Create skill → Upload a skill. Нужно включённое выполнение кода (code execution). Без него скилл тоже работает, но `check.py` не запустится, и сверку цифр придётся делать вручную.

### Чат без поддержки скиллов

Вставьте содержимое `SKILL.md` в инструкции проекта или в начало разговора, а `examples.md` приложите файлом. Правила и примеры будут работать в любой модели; не будет только автоматической проверки `check.py`.

Скилл вызывается командой `/slovo` (в агентах, где скиллы вызываются через слэш) или сам, когда вы просите «перепиши по-человечески», «вычитай», «убери канцелярит».

## Как пользоваться

```text
/slovo перепиши по-человечески docs/report.md
```

Агент правит, прогоняет проверку (если может запускать Python), показывает два-три места «было → стало» и, если где-то не смог понять автора, список «Вопросы автору». Двусмысленное он не угадывает.

Проверку можно запустить и самому, нужен только Python 3:

```bash
python3 slovo/check.py report.orig.md report.md --glossary glossary.md
```

```bash
python3 slovo/tests/run_tests.py
```

Если у вас есть свои пары «исходник → проверенная человеком правка» (`имя.orig.md`, `имя.new.md` в одной папке), добавьте `--pairs папка`: так видно, не стала ли проверка шумнее после ваших изменений.

## English

`slovo` is an agent skill for editing and writing Russian non-fiction so that it reads like a person wrote it, without changing a single claim. It locks numbers, scope, causality, certainty, negation and hedges, keeps the author's dashes and voice, asks instead of guessing on ambiguous spots, and ships a stdlib-only checker with regression tests built from real editing failures.
