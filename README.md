# slovo

![Пост, вставленный из чата с нейросетью: /slovo снимает следы нейросети, а цифра «12 %» и тире остаются на месте; дешёвый хьюманайзер выпалывает тире и пишет «рухнула вдвое», slovo возвращает как было](promo/slovo.gif)

Скилл для ИИ-агентов, который правит русский текст как литературный редактор. Язык меняет, мысль автора — нет. Статьи, колонки, интервью, репортажи, посты, письма, отчёты.

## Что он делает с текстом автора

Правит:

- **Ошибки — все, в любом жанре.** Пропущенные запятые, «из за», слипшиеся фразы, пробел перед запятой. Нарочное («Астанавитесь») остаётся.
- **Язык — по жанру.** Канцелярит, кальки, отглагольные существительные вместо глагола, стёртые метафоры, нейросетевую гладкость. Отчёт и деловое письмо правятся целиком. В статье и колонке голос автора весит больше любого приёма. Пост и реплика в чат получают почти только грамотность. Из промо уходят рекламные штампы.

Не трогает:

- **Факты.** Числа, имена, даты, охват и уверенность каждого утверждения: «совпадает по времени» не становится «из-за», а «три версии не объясняют спад» — «ничто не объясняет».
- **Голос.** Разговорный пост остаётся разговорным, нарочито книжный слог — книжным, страдательный оборот в репортаже — на месте. Реплики героя интервью правятся только на грамотность. Голос не бережётся только по прямой просьбе «перепиши полностью» ([ниже](#переписать-полностью)).
- **Тире, кавычки, ё и прочую типографику**, пока об этом не попросили или этого не требует стайлгайд издания.
- **Ничего не дописывает:** ни связок, ни выводов, ни пропущенного шага рассуждения.

Место с двумя прочтениями скилл не угадывает: оставляет как есть и выносит на поля, в «Вопросы автору» — цитата, оба прочтения, что зависит от ответа. Хороший текст возвращается почти нетронутым, и скилл так и говорит: это нормальный результат, а не недоработка. Стайлгайд издания (имена и названия, ё, числа, кавычки) подключается файлом, его правила важнее умолчаний скилла.

Отличие от «хьюманайзера»: живость не покупается ценой точности. Правка, после которой текст стал живее, но соврал, — провал; точный, но ватный текст — тоже провал.

## Установка

Проще всего — попросить агента: «Установи скилл https://github.com/danzerzine/slovo». Вручную — по инструкции ниже.

Скилл — это папка `slovo` с файлом `SKILL.md` внутри, по открытому формату Agent Skills. Её понимают большинство агентов; различается только место, откуда они её берут. Ниже `danzerzine/slovo` — адрес этого репозитория на GitHub.

### Одна копия для всех агентов

```bash
git clone https://github.com/danzerzine/slovo.git ~/slovo-skill
```

```bash
mkdir -p ~/.agents/skills ~/.claude/skills && ln -s ~/slovo-skill/slovo ~/.agents/skills/slovo && ln -s ~/slovo-skill/slovo ~/.claude/skills/slovo
```

Папку `~/.agents/skills` читают Codex, Gemini CLI, Cursor, GitHub Copilot и OpenCode, папку `~/.claude/skills` — Claude Code (OpenCode читает обе). Обновить скилл: `git -C ~/slovo-skill pull`.

### По агентам

| Агент | Для всех проектов | Для одного проекта |
|---|---|---|
| Claude Code | `~/.claude/skills/slovo/` | `.claude/skills/slovo/` |
| Codex (OpenAI) | `~/.agents/skills/slovo/` | `.agents/skills/slovo/` |
| Gemini CLI | `~/.gemini/skills/slovo/` или `~/.agents/skills/slovo/` | `.gemini/skills/slovo/` или `.agents/skills/slovo/` |
| Cursor | `~/.cursor/skills/slovo/` или `~/.agents/skills/slovo/` | `.cursor/skills/slovo/` или `.agents/skills/slovo/` |
| GitHub Copilot (CLI, VS Code, облачный агент) | `~/.copilot/skills/slovo/` или `~/.agents/skills/slovo/` | `.github/skills/slovo/` или `.agents/skills/slovo/` |
| OpenCode | `~/.config/opencode/skills/slovo/` или `~/.agents/skills/slovo/` | `.opencode/skills/slovo/` или `.agents/skills/slovo/` |

У двух агентов есть своя команда установки:

```bash
gemini skills install https://github.com/danzerzine/slovo.git --path slovo
```

```bash
gh skill install danzerzine/slovo slovo --agent claude-code --scope user
```

`gh skill install` (GitHub CLI) ставит скилл в нужную папку для выбранного агента: вместо `claude-code` можно указать `github-copilot`, `cursor`, `opencode` и другие.

### Claude в браузере и в приложении

Заархивируйте папку `slovo` в ZIP и загрузите: Customize → Skills → «+» → Create skill → Upload a skill. Нужно включённое выполнение кода (code execution). Без него скилл работает, но `check.py` не запустится: цифры агент сверяет вручную, по пяти вопросам из ядра.

### Чат без поддержки скиллов

Вставьте содержимое `SKILL.md` в инструкции проекта или в начало разговора, а `reference.md` и `examples.md` приложите файлами. Правила и примеры работают в любой модели; не будет только автоматической проверки `check.py`.

Скилл вызывается командой `/slovo` (в агентах, где скиллы вызываются через слэш) или сам, когда вы просите «перепиши по-человечески», «вычитай», «убери канцелярит».

## Как пользоваться

```text
/slovo перепиши по-человечески docs/report.md
```

Агент правит, прогоняет проверку (если может запускать Python), отдаёт правку на холодную сверку отдельному агенту по `verify.md`, показывает два-три места «было → стало» и, если где-то не понял автора, список «Вопросы автору». Двусмысленное не угадывает, а спрашивает.

Проверку можно запустить и самому, нужен только Python 3:

```bash
python3 slovo/check.py report.orig.md report.md --glossary glossary.md
```

Для статьи, колонки или интервью добавьте `--genre article`: тогда переписанных фраз должно быть не больше трети, а не половины. Если просили сократить, добавьте `--shortened`: пороги длины не считаются, а число, ушедшее вместе с целиком удалённой фразой, — предупреждение, а не стоп.

```bash
python3 slovo/tests/run_tests.py
```

Если у вас есть свои пары «исходник → проверенная человеком правка» (`имя.orig.md`, `имя.new.md` в одной папке), добавьте `--pairs папка`: так видно, не стала ли проверка шумнее после ваших изменений.

### Переписать полностью

По умолчанию slovo бережёт автора. Когда голос не нужен, а нужен чёткий текст, скажите «перепиши полностью». Скилл напишет текст заново из тех же фактов: главное — в первую фразу, глагол вместо канцелярита, вода, подводки и «я не эксперт, но» уходят целиком. Факт-замок не снимается: «возможно» остаётся «возможно», цифры и охват те же, деятеля, которого нет в исходнике, скилл не вводит. Всё выброшенное он перечисляет отдельно, чтобы автор видел, какие мысли ушли.

Было, 126 слов (пример написан нами):

> Всем привет! Хотелось бы немного поделиться с вами некоторыми мыслями относительно результатов нашей работы за прошедший квартал. Я, конечно, не эксперт в аналитике, но, как мне кажется, можно с определённой долей уверенности говорить о том, что в целом ситуация складывается достаточно неплохо.
>
> Так, по итогам квартала было осуществлено увеличение выручки на 12 % по сравнению с предыдущим кварталом, что, безусловно, не может не радовать. Стоит отметить, что данный рост, возможно, связан с запуском новой версии приложения в марте, хотя это пока не проверяли. Также хотелось бы отметить, что отток клиентов остался примерно на прежнем уровне — около 4 % в месяц.
>
> В связи с вышеизложенным предлагаю в рамках следующего квартала рассмотреть возможность проведения проверки гипотезы о влиянии новой версии на выручку. Буду рад любой обратной связи!

Стало, 62 слова:

> Итоги прошлого квартала в целом неплохие. Выручка выросла на 12 % по сравнению с предыдущим кварталом. Возможно, рост связан с запуском новой версии приложения в марте, но эту связь пока не проверяли. Отток клиентов остался примерно на прежнем уровне — около 4 % в месяц.
>
> Предлагаю в следующем квартале рассмотреть проверку гипотезы о влиянии новой версии на выручку. Буду рад обратной связи.

## Что внутри

- `slovo/SKILL.md` — ядро, которое агент читает при каждом вызове: что отдать человеку, глубина правки по жанрам, что нарушать нельзя, грамотность, проверка после работы (с проверкой без терминала). Для короткого текста больше ничего не нужно.
- `slovo/reference.md` — редакторские приёмы (абзац, порядок слов, фраза, ритм, слово, первый экран), грамотность с разбором спорных случаев, подробности проверки, письмо с нуля, источники. Агент читает его для текстов длиннее ~150 слов.
- `slovo/examples.md` — для статей, колонок и отчётов: пары «было → стало»: хорошие правки (в том числе по правилам Пушкина, Чехова, Оруэлла, Уильямса и Сорд), абзац, который правильно не тронули, и разбор перекрученных правок, каждая из которых выглядит гладко и меняет смысл.
- `slovo/check.py` — сверка правки с исходником, только стандартная библиотека Python. Останавливает правку, если потерялось или появилось число, если «5 %» стало «5 п. п.» или «18 мин» — «18 сек», если тире пропало из фразы, которая осталась. Отдельно показывает места, где фраза получила «вдвое», «обвал», «всей», «поэтому» или потеряла оговорку, — с цитатой, чтобы перечитать. С `--style` ещё и показывает формы, которые стайлгайд издания велит менять («Таллин» → «Таллинн»).
- `slovo/verify.md` — готовое задание для холодной сверки: что отдать отдельному агенту или новому чату и в каком виде он возвращает находки.
- `slovo/tests/` — регрессионные тесты для `check.py`: плохая правка должна быть помечена, хорошая — нет; отдельные случаи проверяют, что честная правка не даёт ложной тревоги. Тесты прогоняются на GitHub при каждом коммите.
- `eval/` — скрипты, которыми мерили скилл: портят отредактированный текст известными ошибками и считают, сколько правка починила, пропустила и сколько сделала лишнего; для текста без эталона считают правки на 1000 слов. Тексты в репозиторий не входят.

## Откуда это

Язык — от Норы Галь («Слово живое и мёртвое») и Корнея Чуковского («Живой как жизнь», откуда само слово «канцелярит»). Ещё три правила взяты у тех, кто сформулировал их раньше всех: называть вещь её именем, а не описательным оборотом (Пушкин, «О прозе»); вычёркивать украшающие определения, но не те, что сужают утверждение (Чехов, письмо Горькому); менять стёртую метафору и эвфемизм на простые слова (Оруэлл, «Политика и английский язык»). Из современных авторов взят один приём и несколько примеров. Приём — от Стивена Пинкера («Чувство стиля»): если автор пропустил шаг между двумя утверждениями, редактор не дописывает его, а спрашивает автора. Примеры — по Джозефу Уильямсу («Style: Lessons in Clarity and Grace»: кто действует, тот подлежащее; известное в начале фразы, новое в конце) и Хелен Сорд (её «зомби-существительные», отглагольные слова вместо глагола). Отношение к автору — ещё от двоих. Пинкер жаловался на корректора, который применял разумные правила механически и испортил ему прозу (интервью CMOS Shop Talk, октябрь 2014): приёмы скилла — такие же правила, не законы. Кредо Максвелла Перкинса, редактора Фицджеральда и Хемингуэя: книга принадлежит автору (А. С. Берг, «Макс Перкинс: редактор гениев»). Принцип «удаляй, не дописывай» и сверка с исходником — от [humanizer-ru](https://github.com/ilyautov/humanizer-ru). Одно правило оттуда убрано сознательно: тире автора здесь не трогаются. Русская проза держится на тире, и выпалывать его ради «нечеловеческого» вида — та же порча, что и канцелярит.

## Как проверяли

- **300 невычитанных постов и комментариев** (Telegram, Пикабу, Smart-Lab, GitHub, vc.ru; 294 написаны до ChatGPT): стопов скрипта 0, пробелов у знаков 75 → 5, слипшихся фраз 115 → 58. В 132 правках, где поменялись слова, сдвига смысла не нашли.
- **43 хороших текста профессиональных авторов**, 47 тысяч слов: две правки на тысячу слов, восемь текстов без правок. Семь лишних правок разобраны, по ним уточнены правила.
- **20 отредактированных отрывков, испорченных скриптом** (217 известных ошибок): починено 215, лишних правок около одной на тысячу слов.
- **44 колонки без редактора**, 16 тысяч слов: 31 правка, все на грамотность, ни одной переписанной фразы.
- **32 аналитических отчёта**, из правки которых вырос скилл: самопроверка пропустила 17 искажений смысла, `check.py` ловит 13, остальные четыре ищет холодная сверка.

Скрипты оценки — в `eval/`. Тексты чужие и в репозиторий не входят.

## English

`slovo` is an agent skill for editing and writing Russian non-fiction so that it reads like a person wrote it, without changing a single claim. It locks numbers, scope, causality, certainty, negation and hedges, keeps the author's dashes and voice, asks instead of guessing on ambiguous spots, and ships a stdlib-only checker with regression tests built from real editing failures.
