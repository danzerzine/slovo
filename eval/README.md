# Оценка правки

Три скрипта, которыми мерили slovo (итоги — в разделе «Как мы проверяли скилл» главного README). Нужен только Python 3, внешних библиотек нет. Тексты сюда не входят: корпус чужой и лежит отдельно.

## Испорченный эталон: `corrupt.py` и `score.py`

Живого редактора, который сверил бы правку, обычно нет. Эталоном здесь служит текст, уже прошедший редакцию издания: скрипт вносит в него известные ошибки и записывает, где каждая.

```bash
python3 corrupt.py src/ 001 002 003 --out set/ --words 400 --seed 1
```

Из `src/001.md` берётся отрывок около 400 слов по границе абзаца. Получаются `set/001.gold.md` (эталон), `set/001.in.md` (с ошибками) и `set/001.sites.json` (места ошибок). Ошибки: пропущенная запятая перед «что», «чтобы», «который»; пробел перед запятой; «из за», «кто то»; слипшиеся фразы; строчная после точки; «-тся» вместо «-ться»; перестановка букв. Отдельно вставляются подводки вроде «Стоит отметить, что».

Скилл правит `set/NNN.in.md`, результат кладётся в `out/NNN.md`. Потом:

```bash
python3 score.py set/ out/ --check ../slovo/check.py --accepted accepted.tsv
```

Для каждого места ошибки счётчик говорит одно из трёх: «починено» (там снова как в эталоне), «пропущено» (как в испорченном) или «иначе». Правки мимо этих мест — лишние, они считаются на 1000 слов. Вставленные подводки идут отдельной строкой: одиночная подводка в колонке может остаться по правилу скилла. Подводку внутри чужой речи (в кавычках или в реплике после тире) счётчик не считает. Итог и список каждой лишней правки в контексте пишутся в `out/_score.txt`.

Опубликованный текст тоже бывает с ошибками, и правка, которая их чинит, лишней не считается. Такие места перечисляются в `accepted.tsv`, по одному на строку, через табуляцию: номер текста, несколько символов перед местом, было, стало. Пустое «было» — вставка:

```
016	нача	ХХ	XX
024	за то		,
```

Проверка самих скриптов: если положить в `out/` эталон, всё починено и лишних 0; если положить испорченный текст, всё пропущено.

## Без эталона: `density.py`

Для текста, у которого нет редакторской версии, например сильного автора без редактора. Хорошая вычитка такого текста — почти одна грамотность, поэтому каждая правка тут под подозрением.

```bash
python3 density.py src/ out/
```

Скрипт печатает таблицу по текстам: слова, правки, из них только знаки, правки слов и правки на 1000 слов. Каждую правку в контексте он пишет в `out/_edits.txt`, чтобы прочитать их все подряд.
